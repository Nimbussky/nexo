# Nexo — V1 Scope

**Product:** Nexo — a real social platform for connecting people and sharing text, images, and video.
**Audience:** Anyone who wants a simple Instagram + YouTube-lite experience in the browser.
**Pronunciation:** NEK-so (easy, two syllables).

## In V1
- Sign up / login / logout (email + password)
- Profile: username, display name, bio, avatar
- Search people
- Follow / unfollow
- Create posts: text, image, or video
- Home feed (followed users + own posts)
- Explore (recent public posts)
- Post detail page
- Responsive web (mobile + desktop)
- Deployable to Vercel
- Full source on GitHub

## Out of V1
- Stories, Reels editor, live, DMs
- Comments / likes (V1.1)
- Push notifications
- Native apps

## Acceptance criteria
1. A new user can register and land on their feed.
2. A user can edit profile (name, bio, avatar).
3. A user can find another user by search and follow them.
4. A user can publish text, image, or video posts.
5. Feed shows posts from followed accounts.
6. Explore shows recent posts from the network.
7. Sessions persist across refresh.
8. Site works on phone-width and desktop.
